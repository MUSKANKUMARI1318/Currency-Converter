# 💱 Currency Converter

A simple and user-friendly Currency Converter built using HTML, CSS, and JavaScript. It fetches exchange rates from a free currency API and converts an entered amount between different currencies.

## ✨ Features

- Convert amounts between different currencies
- Fetch exchange rates using a currency API
- Dynamic currency dropdowns
- Country flags update according to the selected currency
- Simple and responsive user interface
- Automatic exchange rate display on page load

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- [Fawaz Ahmed Currency API](https://github.com/fawazahmed0/currency-api)
- [FlagsAPI](https://flagsapi.com/)

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/MUSKANKUMARI1318/Currency-Converter.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter an amount, select the currencies, and click **Get Exchange Rate**.
